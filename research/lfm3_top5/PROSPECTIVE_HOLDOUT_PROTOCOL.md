# Prospective LFM3 narrative triage gate (research only)

This stack is a **scoring-contract prototype**, not a held-out benchmark run and not release evidence.

1. Freeze `prospective_rule_v1.py`, `prospective_holdout_gate.py`, and `prospective_prereg_v1.json` on a reviewed, immutable commit **before** any independent author reveals future cases, oracle labels, or scoring receipts. Preserve the Git commit plus SHA-256 of the JSON preregistration through separately controlled external custody.
2. A *different* case author creates at least 36 unique sanitized/fictional incident narratives, at least 5 per category and at least 5 tagged instances of each challenge (negation, chronology, ambiguity, distractor, missing evidence, overlap). A separate reviewer adjudicates gold categories and directly supporting evidence markers without inspecting candidate outputs.
3. Seal the canonical dataset hash using an external timestamped, independently witnessed custody mechanism before inference. A caller-supplied matching digest alone does **not** prove authorship, blinding, timestamp, signer separation, or anti-rollback.
4. Run the **same** frozen case IDs once per experimental arm (CPU and resource-approved Vulkan8), across at least two distinct stage/session IDs per mode. Freeze checkpoint digest, inference parameters, prompt template, binary identity, node pressure, cleaning rules and stage order beforehand. Never reuse request IDs, claim sample independence from two arms, or count a repeated prompt as a new case.
5. Score whole raw model replies with the exact two-key JSON oracle. Track exact correctness, unsupported positive attribution, invalid format, correct abstention, rule baseline correctness, and same-request HTTP-plus-local-validation milliseconds. Additional model starts, source verification, contention, energy and independently witnessed kernel execution remain separate.
6. The preregistered *screening* criterion per mode is >=85% exact, >=15 percentage points absolute improvement over frozen rules, **zero wrong positive attributions**, and exact correctness on all insufficient-evidence cases. Meeting it alone does NOT establish generalizability or incremental model value: an independent evaluator must examine uncertainty, adjudication, repeated sessions, distribution shift and artifact custody.
7. Never reveal held-out labels/prompts to an adapting rule author, and never tune baseline prompts/heuristics on held-out failures; any subsequent revision is a new prospective experiment. Public synthetic contract tests are **not** held-out evidence.
8. Only fictional/public synthetic contract code is published here; raw host receipts stay on the authorized local research node. Do not send credentials, private incident narratives, model logs, or infrastructure identifiers to free hosted agents.

Release boundary: no automated source-derived production decision, merge, provider admission, secret access, model change, ingress or deployment. The scoring contract always outputs `model_value_verified=false`, `external_custody_verified=false`, `accelerator_attested=false`, and `production_authorized=false`. Native SGNC external witness and production security gates remain independent.
